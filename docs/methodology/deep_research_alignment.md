# Deep Research 报告吸收与原则校准记录

## 采用内容

本轮把研究报告中的以下内容纳入产品主线：

- 以家庭而非单个投资者为决策单位；
- 联合分析资产、负债、现金流、家庭责任、社会保障、目标、风险和行为；
- CHFH 中国家庭财富健康理论、GRB 动态账户模型、CHFI 十维诊断和 HFDT 家庭金融数字孪生；
- 目标金额、期限、刚性、可延期程度和专项成本增长分开记录；
- 风险承担能力、主观意愿与实际行为分开观察；
- LLM 负责理解和解释，确定性工具负责计算，规则引擎与适当性模块拥有硬否决权；
- 个人养老金作为制度账户处理，账户外壳与底层产品风险分开；
- 从一次推荐升级为家庭状态变化驱动的持续复盘；
- CHFI 只用于家庭诊断，不用于征信、贷款定价或歧视性营销。

## 按产品原则调整的内容

| 报告原方向 | 本产品执行口径 |
| --- | --- |
| 四个功能账户不设统一比例 | 保留用户指定的四账户框架。要花和保命不按家庭总资产固定比例；保本设置 5%-30% 观察带；生钱设置合格长期剩余资金 70% 以上的战略目标。所有比例必须显示分母与适用条件。 |
| 先满足前三层，再允许增长账户 | 增加地区化启动线。默认约 50 万元，一线与新一线可在 50 万-100 万元间调整，其他地区可在 30 万-50 万元间调整。 |
| 低于启动线不进入增长账户 | 正式增长金额为 0。中青年家庭仅在有正结余、无待处理高息债务、前置安全条件完成且通过适当性时，可使用多余长期资金不超过 10% 的宽基指数学习仓。 |
| 流动性账户覆盖现金流缺口 | “要花的钱”只承担信用卡结算与货币基金等数千元日常周转。较大的应急储备允许放入保本账户中便于申赎的稳健工具。信用卡额度不是资产。 |
| 保障账户按缺口配置 | 保留“保险只消费、不投资”的客户语言。系统按医疗、重疾、意外、身故责任和车产责任测算保障缺口，保额不计入资产，保费作为年度现金流。 |
| 财富安全账户按目标成功概率配置 | 对外继续使用“保本的钱”作为用途名称，覆盖应急、大额支出、个人养老金、教育金、债券和期限匹配的稳健安排。名称不代表底层产品保证本金。 |
| 增长账户使用组合优化技术 | 普通家庭优先宽基指数和分散工具，不默认推荐个股、杠杆、股指期货或新增投资性房产。专业对冲需求必须转人工并通过完整适当性审查。 |
| 长期实际财富增长 | 地区最低工资滚动涨幅保留为长期购买力辅助信号，并与官方 CPI、家庭支出加权变化和目标专项成本分开。它不是 CPI，也不是收益保证线。 |

## 未直接采用的内容

- 报告中的检索占位引用不能作为正式可核验引文，产品不把这些占位标识写入客户界面或审计证据。
- 报告中的全国性固定结论或当前市场判断，只有进入受控快照、记录来源和有效日期后才能参与计算。
- “保本且跑赢”只作为家庭长期规划目标，不转写为任何基金、理财、保险或组合的本金与收益承诺。
