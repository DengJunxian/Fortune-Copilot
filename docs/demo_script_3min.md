# 智运财富 Fortune Copilot 三分钟演示脚本

版本：1.0  
对应页面：http://localhost:8080/demo  
备用端口：http://localhost:18080/demo  
演示账号：顶栏“演示管理员”启动主流程；跳转三端后按脚本切换模拟账号  
数据边界：A-H 八类合成 Persona、Mock LLM、Mock 银行适配器、离线规则；非工商银行官方产品

## 演示前准备

1. 执行 `docker compose up --build`，确认 `/api/v1/health` 返回 `0.14.0 / demo / mock`。
2. 执行 `make warmup`；若使用备用端口，执行 `API_URL=http://127.0.0.1:18000 make warmup`。
3. 打开 `/demo`，确认发布清单为“可演示”、三套家庭已加载、外部网络依赖为“否”。
4. 点击一次“一键运行完整 Demo”。正式演示时可以直接使用已完成记录，也可以现场重新运行。
5. 浏览器缩放 90%–100%，关闭无关标签页。演示全程不输入真实身份证、账号、手机号或 API Key。

## 0—20 秒：相同资产，不应得到相同比例图

**页面与动作**：停留在 `/demo` 顶部，指向“同一引擎，三种家庭配置”与 A/B/C 对照表，不点击任何账户比例切换。

**逐句台词**：

> “先做一个最简单的反例：即使两个家庭都有 100 万元金融资产，只要一个有房贷和十年教育金，另一个临近退休且收入更稳定，他们就不该收到同一张比例图。智运财富不是把标准普尔四象限换成中文，而是先读家庭责任、目标、负债和保障，再计算资金用途。这里 A、B、C 用同一套规则，实际得到三个不同配置签名，系统明确返回 `fixed_ratio_model=false`。”

**屏幕证据**：A/B/C 生命周期、应急月数、保障缺口、四账户金额和三个不同的配置签名。此段的“同样 100 万”是问题设问，不宣称三个 Demo 家庭实际资产相同。

## 20—50 秒：家庭建档与自动识别

**页面与动作**：在十阶段时间线定位“自然语言确认”；展开该阶段证据。若需要现场重跑，点击“一键运行完整 Demo”，等待第 2 阶段完成。

**逐句台词**：

> “客户只需要从家庭语言开始：‘我和爱人月工资合计三万元，房贷八千，孩子上幼儿园。’模型只负责理解，先生成待确认草稿。三万元、八千元、配偶关系和幼儿园阶段逐项勾选；没有说出的房贷余额、利率和期限继续保持缺失，绝不让模型补数。确认后的事实才进入统一家庭账本，所有金额保留来源、数据日和版本。”

**屏幕证据**：第 2 阶段状态、解析器版本、确认字段数、缺失字段数和审计记录。

## 50—90 秒：财务体检

**页面与动作**：点击“查看客户端规划书”进入 `/client`；顶栏选择“客户 · 李先生”，打开“财务健康”任务。依次指向应急储备、偿债负担和房产集中度；不切换到营销式收益图。

**逐句台词**：

> “确定性引擎先做五张底表，再做 20 项指标。这个育儿家庭总资产 285 万元、负债 120.8 万元，年结余 7.2 万元。真正影响决策的是：应急储备只有 4.17 个月，而动态安全目标是 7 个月；偿债负担率 20%；房产占总资产 84.21%；主要保障缺口 145.2 万元。信用卡额度从未进入资产，未付款才进入负债。每个数字都能展开公式、分子、分母、数据日和记录来源。”

**屏幕证据**：指标账本与公式抽屉；若页面加载失败，回到 `/demo` 的第 3 阶段证据读取同一计算摘要。

## 90—130 秒：目标与动态四账户

**页面与动作**：在 `/client` 点击“目标时间轴”，指出十年教育目标；再点击“动态四账户”，在金额/比例视图中依次展示家庭总资产、可投资金融资产、年度新增结余三种分母。

**逐句台词**：

> “十年教育目标不是今天的金额直接除以十年，而是按专项成本增长计算未来金额、现值、缺口和月投入。四账户随后按七步瀑布分配：先高息债务，再日常、应急、保障、近期目标，最后才是长期资金。比例必须说明三把尺：家庭总资产、可投资金融资产、年度新增结余。这个家庭建议先补 8.3 万元安全层和近期目标，长期新增金额是 0 元。所谓 70%，只可能作用于通过全部安全闸门后的长期可规划资源，绝不是全家总资产的统一 70%。”

**屏幕证据**：十年目标、七步瀑布、三尺切换、五硬一软约束和生钱账户 0.00 元。

## 130—160 秒：失业 + 市场下跌压力测试

**页面与动作**：点击“数字孪生”，选择或读取已经完成的“失业 6 个月 + 权益下跌 30%”结果；指向原方案/优化方案成功率、耗尽概率、被迫出售概率和 P10–P90 扇形。

**逐句台词**：

> “我们不预测市场，而是问家庭能不能扛住条件冲击。固定 seed 的 100 条路径里，原方案目标成功率是 53%，资金耗尽概率 39%，被迫出售概率 100%；在补足安全层、调整储蓄和长期资金后，同一组随机路径下成功率为 100%，耗尽为 0%，被迫出售为 4%。这是合成参数下的压力测试，不是收益预测；共同随机数让前后差异来自方案，而不是换一批随机数。”

**屏幕证据**：场景名、seed、路径数、原/优化结果、参数哈希、版本和“不构成预测”说明。

## 160—180 秒：行为、可信解释、三端闭环与工行价值

**页面与动作**：回到 `/demo` 第 7—10 阶段，快速指向“损失厌恶/48 小时冷静期”“顾问—合规—客户”“严格八章报告”“九智能体终检”；随后依次打开客户经理端 `/advisor` 与风险合规端 `/risk`，读取同一方案版本和审计 ID，不等待展开非核心附录。

**逐句台词**：

> “问卷说能承受波动，但 -10% 就清仓，行为证据把风险上限下调并触发 48 小时冷静期。客户经理看到三方案和沟通底稿，合规看到规则、引用、模型版本和审计链，客户只看到合规后的同一版本。对工行的价值不是多卖一个产品，而是把家庭综合金融、养老服务、客户经理效率、适当性、消费者保护和长期陪伴放进同一条可追溯链。全程不需要外部模型、真实银行接口或网络。”

**收束台词**：

> “智运财富不是替用户预测市场，而是帮助中国家庭在不确定的市场中，仍然能够完成确定的人生目标。”

## 现场压缩与恢复

| 风险 | 现场动作 | 可继续陈述的证据 |
| --- | --- | --- |
| 主 Demo 重跑超过 3 秒 | 立即切换到已完成的最新运行 | 十阶段状态、耗时、版本和审计 ID 已持久化 |
| `/client` 页面加载失败 | 回到 `/demo` 展开第 3—7 阶段 | 同一确定性结果已在主运行摘要中保存 |
| 图表渲染异常 | 打开“等价数据表” | 数值、单位、数据日和来源不依赖图形 |
| 浏览器断网 | 保持本地 Compose，不刷新外部资料 | 主链无 CDN、字体、行情、外部模型依赖 |
| 合规流程状态不在预期 | 使用已完成运行的“查看三端结果”入口 | 不跳步、不伪造审批；必要时只展示审计链 |
| 端口冲突 | 使用 18000/18080 备用端口 | 运行前写入演示提示卡，不现场改代码 |

完整故障处理见 [Demo 运行手册](demo_runbook.md) 与 [演示风险预案](demo_risk_plan.md)。
