# Fortune Copilot 比赛演示风险预案

## 演示目标与不可牺牲项

现场优先证明六件事：懂中国家庭、方案因人而异、关键数字由确定性工具计算、AI 受规则约束、三端闭环可运行、无外部服务仍可完成。时间不足时可以缩短页面浏览，但不得省略 Mock/合成边界、适当性、分母和非保本说明。

## T-30 分钟检查

```bash
docker compose ps
curl -fsS http://127.0.0.1:8000/api/v1/health
make warmup
make acceptance
```

若 8000/8080 被占用：

```bash
BACKEND_PORT=18000 FRONTEND_PORT=18080 docker compose up --build
API_URL=http://127.0.0.1:18000 make warmup
API_URL=http://127.0.0.1:18000 WEB_URL=http://127.0.0.1:18080 make acceptance
```

确认项：版本 0.13.0、`runtime_mode=demo`、`mock_mode=true`、数据库 healthy、三户已加载、最新运行 completed、外部调用 0、浏览器无控制台错误。演示机只保存 `.env` 示例值，不输入或展示真实 API Key。

## 现场故障分级

| 等级 | 现象 | 恢复动作 | 禁止动作 |
| --- | --- | --- | --- |
| P0 | 页面/API完全不可用 | 切换到备用端口；重启当前 Compose；使用已验证 PPT 截图完成叙事 | 临时连接陌生网络、修改生产性配置、展示真实数据 |
| P1 | 主 Demo 某阶段失败 | 保留失败记录，点击“从失败记录安全重试”；或打开最新 completed 运行 | 删除失败证据、手工改数据库伪造完成 |
| P1 | 数据集不完整 | 管理员执行“加载 A/B/C”；必要时显式“重置合成数据” | 重置非合成数据或临时导入个人信息 |
| P1 | 报告/工作流不在客户可见状态 | 使用管理员/合规账号查看证据；解释服务端门禁 | 跳过审核状态、给客户暴露内部资源 |
| P2 | ECharts 未渲染 | 展开等价数据表和文字结论 | 用手写数字替代后端结果 |
| P2 | 外部模型不可用 | 保持 Mock/模板解释继续 | 现场粘贴密钥、降低数字计算边界 |
| P2 | 网络完全断开 | 不处理；本地 Compose 和所有资源可继续 | 刷新外部官方资料或 CDN 页面 |
| P3 | 字体/缩放异常 | 浏览器恢复 100%，使用系统字体；切换 1366/1440 视口 | 下载未知字体或覆盖设计令牌 |

## 数据与状态恢复

- `make reset-demo` 只删除并重建 `is_synthetic=true` 的家庭；production 禁止。
- 主运行、失败和重试均持久化，不覆盖旧证据。
- 备份：`make backup-demo OUTPUT=/absolute/path/demo.sqlite`。
- 恢复会替换演示数据库，必须停止写入并使用显式确认；恢复前自动创建带时间戳副本。
- 演示前保留一份已通过验收的 synthetic-only 备份和 SHA-256 清单；不要将外部或个人数据混入。

## 叙事降级路线

1. **正常路线**：`/demo` → `/client` → `/advisor` → `/risk`。
2. **页面局部故障**：只在 `/demo` 展开十阶段摘要、三家庭对照和三端入口，使用持久化证据完成讲解。
3. **浏览器不可用**：使用比赛 PPT 中的实际截图；同时在终端展示健康、manifest 和 acceptance JSON。
4. **容器不可用**：使用最终验收报告和上一次通过的测试日志；明确说明“现场运行环境故障”，不得声称正在实时计算。

## 常见追问的证据入口

| 追问 | 现场入口 |
| --- | --- |
| 四账户是不是固定比例 | `/demo` 三家庭对照：3 个唯一签名、`fixed_ratio_model=false` |
| 70% 的分母是什么 | `/client` 动态四账户：三尺；规则说明“扣除优先债务后的可规划资源” |
| 信用卡额度在哪里 | `/client` 资产负债/Mock 银行快照：额度单列，不进入资产 |
| 大模型是否计算数字 | `/risk` 九智能体工具账本与发布门禁 |
| 压力测试是否预测 | `/client` 数字孪生：场景、seed、参数和“不构成预测” |
| 是否接工行真实接口 | `/demo` 发布边界、Mock 适配器清单 |
| 如何保护隐私 | `/client` 隐私中心、`/risk` 审计与安全评测 |
