# Personal Pension Copilot

## 产品语义

个人养老金是制度账户外壳，不是资产类别。账户内的存款、国债、理财、保险、债券基金和指数基金具有不同本金风险、波动与流动性，不能因为处于养老金账户就自动归为低风险或“保本”。

## 当前输出

- 资格状态与需要补充的信息。
- 年度缴存金额、政策限额、进度和剩余额度。
- 基于已确认边际税率的当年税收利益估算。
- 账户余额和逐资产风险标签。
- 领取前锁定状态与退休投影可用性。
- 年度缴存提醒状态。

年度限额和领取税率来自版本化 `PensionPolicySnapshot`，不硬编码在 Python 中。比赛数据明确标记为 demo snapshot；政策变更必须发布新版本并保留历史版本。

## 流动性纪律

养老金资产分成 `locked_institutional_assets` 和 `withdrawable_institutional_assets`。锁定余额不能满足日常周转、应急储备或近期刚性目标；只有已经符合法定领取条件且满足真实赎回时间的资产，才可进入可领取汇总。

## 与养老责任联动

`InstitutionalCoverageSummary` 汇总社保、企业/职业年金、公积金和个人养老金，并通过 `RetirementIncomeFloorCoverage` 比较确定性退休收入与最低退休生活责任。资金余额与未来收入覆盖是不同维度，数据不足时返回 `needs_review`，不虚构未来养老金。

## 生产缺口

真实业务仍需接入客户养老金账户、税务适用信息、社保与年金权益、产品主数据、缴存交易和领取规则。当前页面和服务只使用客户确认信息及受控政策快照，不代表已接入工行或政府实时系统。
