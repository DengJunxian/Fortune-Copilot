# 阶段 1 产品设计报告

## 产品命题

智运财富不是把国外固定比例图换成中文，而是把中国家庭的目标、责任、现金流、住房集中、社会保障、养老、赡养、教育和行为偏差转为可计算的顺序约束。

## 当前产品切片

阶段 1 交付三端共同底座：

- 客户端展示四账户瀑布的正确顺序和能力边界；
- 顾问端展示 real、mock、planned 的工程能力矩阵；
- 风险端展示七项不可妥协规则；
- 三端共享 API 状态、设计系统、离线 Mock 和竞赛原型声明。

这不是完整业务 MVP。家庭金额、财务报表和配置在确定性引擎完成前不出现在页面，避免用演示常量冒充计算。

## 视觉主张

视觉气质是“可信、克制、温和的数据秩序”。浅色默认降低家庭用户认知压力；深蓝建立专业锚点；品牌红用于关键行动；暖金留给人生目标；橙色用于预警；绿色只用于已经完成或已经通过。

三端共享组件，不复制三套设计：客户端间距更舒展，顾问端信息更紧凑，风险端优先证据和规则。所有页面明确标注竞赛原型，避免造成工商银行官方产品混淆。

## 关键交互原则

1. 先显示结论口径，再允许查看公式和证据。
2. 比例必须有分母、时间和适用条件。
3. 任何建议都需显示受限原因和改变什么会改变结果。
4. 网络或模型失败时保留确定性主流程，并显示真实降级状态。
5. 风险信息不因低金融知识模式而删除，只改写解释方式。
