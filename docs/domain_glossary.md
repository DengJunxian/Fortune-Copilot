# 领域词汇表

## 理论框架

| 术语 | 正式定义 |
| --- | --- |
| 一核 | 家庭人生目标、家庭韧性与长期生活质量 |
| 四账 | 要花、保命、保本的钱、生钱四类用途账户，不是固定比例象限 |
| 三尺 | 家庭总资产、可投资金融资产、年度新增结余三种核心分母 |
| 五硬一软 | 流动性、偿债、保障、目标期限、风险适当性五项硬约束，加行为承受力软修正 |
| 双画像 | 家庭财务画像与行为金融画像 |
| 四维风险 | 风险能力、风险意愿、产品理解能力、实际风险行为，冲突时取更审慎上限 |
| 六阶段 | 初入职场、婚姻组建、育儿成长、家庭成熟、退休准备、养老传承 |
| 北极星指标 | 家庭核心目标按期实现概率，而非预测收益率 |

## 四账户

| 账户 | 定义 | 禁止误解 |
| --- | --- | --- |
| 要花的钱 | 未来 30-90 天日用支付与确定性账单周转 | 不按总资产固定 10%；信用卡额度不是资产 |
| 应急储备 | 收入中断与意外支出缓冲，通常按 3-12 个月必要支出动态计算 | 不与日常周转混为一项 |
| 保命的钱 | 根据身故、失能、医疗、重疾、意外等保障缺口确定的风险转移安排 | 不按固定保费比例；不把保额、保费和现金价值重复计入 |
| 保本的钱 | 匹配未来 1-5 年刚性目标、较大支出和债务缓冲的稳健目标账户 | “保本账户”不等于银行理财、基金、信托或保险保本 |
| 生钱的钱 | 正式配置为通过完整约束后的五年以上长期增长资金；门槛下可另设不超过多余长期资金 10% 的宽基指数学习仓 | 学习仓不是正式配置或收益目标；70% 只可能对应正式配置的长期可投资资金，不对应家庭总资产 |

## 关键口径

| 术语 | 定义 |
| --- | --- |
| 家庭总资产 | 家庭拥有且可可靠计量的资产市值总和，不含信用卡可用额度 |
| 可投资金融资产 | 排除自住使用资产等后，可用于配置的金融资产，具体范围由规则版本定义 |
| 流动金融资产 | 可在规定天数内以可接受折价变现的金融资产 |
| 年度新增结余 | 年度税后可持续收入减年度支出与债务本息后的剩余 |
| 长期可投资资金 | 完成高息债务、流动性、应急、保障和 1-5 年刚性目标锁定后的剩余长期资金 |
| 信用卡未付 | 已发生但未偿还的短期负债 |
| 备用授信信息 | 信用卡额度等可用信贷，只单独展示，不进入资产、净资产或流动覆盖 |
| 家庭 CPI | 按家庭实际消费权重计算的个性化消费价格变化 |
| 民生收入追赶基准 | 地区最低工资滚动增速，只是长期辅助信号，不是 CPI 或收益保证线 |

## 数据与 AI

| 术语 | 定义 |
| --- | --- |
| 确定性工具 | 给定相同输入和版本产生相同结果的财务计算与规则函数 |
| LLM Provider | 只负责语言理解、缺失项追问和解释的可替换接口 |
| Mock Provider | 不调用外部网络的本地确定性模板 Provider |
| 受控 RAG | 带标题、机构、日期、生效范围、段落和哈希的政策与产品知识检索 |
| 混合检索 | 先做类别、人群、地区、生效期与安全过滤，再组合关键词、离线向量和元数据分数的可复现排序 |
| 受控知识切片 | PolicyDocument 下带页码／段落、关键词、哈希、向量和安全状态的最小引用单元 |
| 提示注入隔离 | 将文档或用户输入里的“忽略规则”等指令视为不可信数据；命中切片不参与检索或生成 |
| 待确认录入草稿 | 自然语言解析出的候选字段；每项需用户核对，缺失值不猜测，草稿不等于正式家庭事实 |
| 数字工具账本 | 智能体运行中保存的数字 code、值、单位、确定性工具、来源路径和值哈希；解释只能逐值引用 |
| 九智能体状态机 | 信息采集→财务报表→财务诊断→目标规划→行为金融→资产配置→政策知识→报告生成→合规审计的不可跳步链 |
| 反幻觉终检 | 对输出中的数字、政策、产品版本、提示注入、禁止性承诺和高风险建议执行的确定性校验 |
| 适当性三道闸门 | 家庭安全、客户适当性和产品适当性 |
| 方案版本 | 保存输入快照、规则、模型、产品库、知识库、随机种子和审计事件的不可覆盖版本 |
| 合成数据 | 为比赛和测试人工构造、不对应真实客户的数据 |
| Mock API | 符合接口契约但不连接真实银行生产系统的模拟适配器 |
| 乐观版本 | 每次更新或软删除递增的记录版本；客户端提交预期版本以阻止并发覆盖 |
| 软删除 | 保留记录与审计字段、但从普通业务查询隐藏的删除方式 |

| 战略配置 | 由长期目标、风险和多目标规则确定的长期资产类别中枢，不随短期市场观点任意改变 |
| 战术配置 | 三道闸门通过后，围绕战略配置最多 5 个百分点的受限情景偏移 |
| 规则型降级 | 优化无可行解或失败时使用版本化审慎权重，并公开状态和原因，不伪装为优化成功 |
| 确定性情景成功率 | 固定离线情景中达到目标阈值的权重之和，不是 Monte Carlo、历史回测或收益承诺 |
| 教育展示 | 只解释资产／产品类型和风险，不代表候选可执行、可销售或已通过适当性 |
| 家庭财富数字孪生 | 从家庭事实出发、按版本化规则逐月更新收支资产负债和目标的可复现状态模型，不是对真实未来的确定预测 |
| Monte Carlo 路径 | 在固定 seed、假设和相关结构下生成的一条随机状态序列；路径数量是模拟样本数，不是客户数量 |
| 分位数扇形 | 同一时间点路径分布的 P10／P25／P50／P75／P90 区间；阴影表示不确定性，不是保证范围 |
| 共同随机数 | 基线、原方案和优化方案对同一 path_id 使用相同随机流，使差异主要来自显式方案而非重新抽样 |
| 压力场景组合 | 最多六个版本化收入、家庭、目标、市场、债务或生命周期冲击按明确规则合成，不是自然语言任意相加 |
| 资金耗尽 | 路径中生活或债务支出无法足额支付并形成未履行义务；不同于净资产仅因房产估值为负 |
| 被迫出售 | 退休目标之外，为现金缺口卖出长期资产；正常退休提款和退休目标计划性提取不计入 |
| 原方案压力 | 在所选压力和基础假设下保留现有家庭计划的路径分布 |
| 优化方案压力 | 与原方案使用共同随机数，只应用明确退休年龄、储蓄、权益和流动性反事实的路径分布 |

## 行为金融

| 术语 | 定义 |
| --- | --- |
| 七维问卷 | 风险意愿、自述损失承受、投资经验、金融知识、交易克制度、注意力稳定和目标纪律的定点输入 |
| 六项行为实验 | 上涨 20%、下跌 10%、下跌 30%、热门产品、盈亏处置和消费／目标选择；记录选择、反应时间、修改次数和一致性 |
| 行为双画像 | 问卷自述画像与实验行为画像的并列证据；再与客观风险能力取审慎最低上限，不做平均 |
| 偏差证据 | 十一项偏差各自的问卷或实验来源、观察、贡献、分数和解释；不是临床诊断或监管评级 |
| 强制冲突下调 | 自述与选择冲突时用明确规则降低实验上限，例如自述可承受 30% 却在 -10% 清仓 |
| 行为干预 | 根据偏差、家庭目标和场景选择的冷静期、分批、预先承诺、目标提醒等行动；不自动交易或承诺收益 |
| 冷静期 | 高追涨／从众／近期偏差信号触发的 24 或 48 小时等待；开始和可操作时间可审计 |
| 合格 A/B 数据 | `eligible_data=true` 的合成或明确授权测试会话；只用于描述实验管线，不证明因果效果 |

45 个领域实体、字段类型和枚举 API 值见 `docs/data_dictionary.md`，关系见 `docs/er_diagram.md`。

## 报告结构

正式规划书一级目录固定为八章：家庭基础情况、理财目标、大额支出计划、理财假设、家庭财务报表、家庭财务比率分析、投资规划建议、免责声明。压力测试、行为金融、养老、保险、债务、四账户与行动日历只能进入第 7 章二级目录或附录。
