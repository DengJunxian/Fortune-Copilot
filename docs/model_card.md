# Fortune Copilot 模型卡

## 模型系统概览

Fortune Copilot 不是“让一个大模型完成理财规划”的系统。关键金额、比率、目标现值、账户分配、产品适当性、压力路径、行为评分和报告一致性全部由版本化确定性工具计算。语言模型只可用于理解、追问和解释。

| 组件 | 默认实现 | 是否联网 | 数字权限 |
| --- | --- | --- | --- |
| 信息抽取 | 确定性中文解析器 | 否 | 只抽取原文明确值，写入前逐项确认 |
| RAG | 本地受控关键词 + 64 维哈希向量 | 否 | 只返回受控切片和引用 |
| 解释 | Mock 模板 | 否 | 只复述已验证结果 |
| 正式报告 | 确定性八章编排器 | 否 | 只消费数字账本和受控引用 |
| 外部兼容 Provider | 可选 OpenAI-compatible / DeepSeek | 是，默认关闭 | 无关键数字生成权，响应须通过 Schema 与治理终检 |

## 允许用途

- 理解用户自然语言意图；
- 识别尚缺字段并发起追问；
- 将确定性工具结果转换为低金融知识可读解释；
- 按受控引用解释政策或产品边界；
- 组织不改变数字、来源和八章目录的表达草稿。

## 禁止用途

- 计算或猜测金额、比率、配置、收益率、成功概率或风险等级；
- 编造政策、产品、银行接口、真实客户数据或来源；
- 绕过家庭安全、客户适当性、产品适当性、授权或人工复核；
- 承诺保本、收益或干预效果；
- 把信用卡额度计入资产；
- 把四账户改成固定比例，或把长期增长账户 70% 解释为家庭总资产统一配置；
- 把最低工资等同 CPI；
- 默认向普通家庭推荐个股、杠杆、场外配资或股指期货；
- 自主交易、签署、审批、发布报告或作出法律/医疗/税务决定。

## 输入数据

外部模型只接收字段白名单中的最小上下文：意图、缺失字段、已验证陈述/事实引用、引用 ID、风险标记、语言和语气。直接身份字段、银行账号、手机号、邮箱、地址、生日、API Key、Authorization 和 Token 被字段级阻断或文本级脱敏。

系统提示只声明职责和输出 Schema；不会把完整家庭数据库、完整提示词、会话秘密或审计载荷发送给 Provider。生产外部调用要求 HTTPS 且 hostname 在 `LLM_ALLOWED_HOSTS` 明确列表。

## 输出约束

1. 请求携带 JSON Schema；
2. 传输响应先解析为 JSON 对象；
3. 应用层再由具体 Pydantic 模型校验；
4. 数字、政策、产品和禁止性表述由确定性治理规则复核；
5. 失败或不一致时采用本地模板，不把未验证输出写入正式事实。

## 已知限制

- 确定性中文解析器只覆盖受控的金额、关系和阶段表达，不理解任意自然语言合同。
- 本地哈希向量适合当前小型知识快照，不是通用语义搜索；低相关文本可能需要元数据过滤或人工查询。
- Prompt 注入检测是规则与受控语料隔离的组合，不是对所有未知攻击的证明。
- 外部 Provider 的可用性、服务端留存、区域、延迟和模型更新由供应商控制；启用前必须完成供应商与数据处理评估。
- 模板解释可读性有限；“解释成功”不等于建议适当、事实有效或法律合规。
- 模型台账中的测试指标不能外推为生产准确率、收益或客户行为效果。

## 失败模式与安全降级

| 失败 | 处理 |
| --- | --- |
| 无 API Key / Provider 配置不完整 | 工厂返回 Mock Provider，不发网络请求 |
| Provider 超时、断网、HTTP 错误 | `generate_validated` 返回 Pydantic 验证的本地模板和 failure_code |
| 非 JSON / Schema 不匹配 | 丢弃响应，返回本地模板 |
| RAG 零命中 | 返回“依据不足”，引用为空，要求补充问题或转人工 |
| 过期/尚未生效/隔离切片 | 不进入回答 |
| 用户或文档提示注入 | 调用前阻断或将文档 quarantined，要求人工复核 |
| 禁止性表述或无引用事实 | 治理终检/发布门禁阻断 |
| 数字不一致 | 报告门禁阻断，不允许发布 |

无论模型是否可用，财务、规划、组合、孪生、行为和八章报告的确定性主链都可在 Mock 模式运行。

## 运行台账

`ModelRun` 分别记录 `information_extraction`、`rag`、`report`、`explanation` 四类任务，包含 Provider、模型、Prompt 哈希、输入字段名、脱敏输入、结构化输出摘要、开始/结束时间、降级、注入标记、人工复核要求和失败原因。台账不保存 API Key、完整提示词或直接身份值。

九智能体运行会为上述四类任务各写一条台账；独立录入、RAG 和正式报告也按各自任务记录。每条运行同时写去标识 AuditEvent。

## 监控

测试面板展示：计算正确率、引用覆盖率、无依据事实率、适当性阻断率、提示注入阻断率、报告一致率、运行时间、失败率、四类模型运行数量和发布门禁状态。所有指标均标记 `environment=test` 和 `not_production_metric=true`。

生产监控仍需接入外部可观测平台，并至少监控：降级率、Schema 失败率、零命中率、注入命中率、门禁阻断原因、人工复核积压、Provider 延迟/错误、授权失败和跨家庭拒绝。不得把提示词、身份字段或完整财务载荷写入监控标签。

## 人工复核

以下情况必须转人工：报告发布、任何高风险或边界建议、RAG 无结果、Prompt 注入、模型降级、授权争议、删除请求、无来源政策事实、数字不一致、复杂产品、客户能力/意愿/行为冲突。报告发布还必须由 compliance/admin 明确勾选人工复核并通过十项门禁。

## 版本与责任

- 模型台账契约：`model-risk-ledger-v1.0.0`
- 对抗套件：`security-adversarial-suite-v1.0.0`
- 发布门禁：`pre-publication-quality-gate-v1.0.0`
- 默认模板：`wealthtwin-template-v1`

模型卡应在 Provider、字段白名单、Prompt、输出 Schema、知识库、治理规则或人工复核条件变化时更新。当前只适用于竞赛 Mock/测试环境。
