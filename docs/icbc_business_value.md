# 智运财富 Fortune Copilot：工商银行业务价值与落地边界

## 定位

Fortune Copilot 的建议定位是“家庭综合金融服务与方案治理工作台”，不是单一基金销售工具，也不是替代客户经理、风险合规或持牌投顾的自动交易机器人。当前交付是竞赛原型：只使用合成家庭、Mock 产品和 Mock 银行适配器，非工商银行官方产品，未接入工行数据、系统或真实业务流程。

## 建议落地路径

1. **离线共创**：由财富、个金、养老、风控、消保、法务和科技共同确认字段、口径、禁令与适当性映射。
2. **影子评估**：使用脱敏历史或专门合成数据，系统只读、不给客户展示；与持牌客户经理结论对照，记录差异而不自动采纳。
3. **内部辅助**：在明确职责分离、人工复核、模型风险和审计制度后，先服务客户经理准备与解释，不开放交易执行。
4. **授权试点**：选择自愿、可退出的小范围客户，验证理解度、计划完成、服务工时、适当性一致性和投诉回放。
5. **规模评审**：只有安全、消保和业务指标同时满足门槛，才评估只读银行适配和后续交易链；每一步保留回滚和人工接管。

## 评价指标建议

业务评价不应只看产品转化。建议至少同时观察：

- 客户是否理解信用卡、非保本、三尺和 70% 条件；
- 顾问准备与复盘工时是否下降；
- 适当性判断一致率和人工改写原因；
- 报告数字/引用覆盖、版本完整和审计回放成功率；
- 应急、保障、偿债和目标行动的完成/延期原因；
- 客户授权撤回、投诉和误解情况；
- 家庭综合资产留存和养老服务使用，但不把短期收益率作为唯一成功标准。

当前仓库中只把工程评测与合成/授权实验协议标为已完成；任何经营指标都必须由工商银行在真实授权试点中重新定义和验证。

## 红线

- 不把竞赛原型称为工行官方产品；
- 不把 Mock 接口或合成指标称为真实接入/经营结果；
- 不为促进销售绕过家庭安全、适当性或人工复核；
- 不把银行理财、信托、基金或保险统一称为保本；
- 不将信用卡额度计入资产；
- 不把长期账户 70% 套用于家庭总资产；
- 不默认向普通家庭推荐个股、杠杆或股指期货；
- 不让大模型计算或改写关键金额、比例和配置。
